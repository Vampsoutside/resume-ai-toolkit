# Contributing to Resume AI Toolkit

Thank you for your interest in improving this toolkit.

## Ways to Contribute

- Improve existing skill instructions (clarity, edge cases, better examples)
- Add new skills (cover letter, LinkedIn optimizer, negotiation practice, etc.)
- Improve documentation or the cheat sheet
- Report issues or suggest features
- Share real before/after results (anonymized)

## Guidelines for New Skills

1. Follow the same `SKILL.md` structure:
   - YAML frontmatter with `name` and `description`
   - Clear core mission
   - Required inputs
   - Strict process / framework
   - Defined output format
2. Keep instructions opinionated and rigorous — do not flatter weak content.
3. Never invent experience or metrics for the user.
4. Test the skill with at least 2–3 real resume/JD examples before submitting.

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`feature/new-skill-name` or `fix/skill-name`)
3. Make your changes
4. Open a Pull Request with a clear description of what changed and why

## Code of Conduct

Be respectful, constructive, and focused on helping job seekers. Harassment or spam will not be tolerated.
